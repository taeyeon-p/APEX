QUADROTOR PID
OPTIMIZATION UNDER
COMPOUND DISTURBANCES

    
배송 임무 조건을 모사한 바람·적재질량 복합 외란 하 쿼드콥터 PID 게인 최적성 분석 및 강화학습 기반 적응형 튜닝과의 비교.


    

      
FIELD
CONTROL / UAV

      
PLATFORM
F450 / PIXHAWK 2.4.8

      
SOFTWARE
ARDUPILOT / PYTHON

      
METRIC
ITAE

    


    

    

      

        PHASE 1 — SITL + 실기 실험
        
바람 강도와 적재 질량을 복합 외란 변수로 설정하고, Roll / Pitch 자세 안정화에 대한 PID 게인 최적성을 ITAE 기준으로 분석합니다. 총 54회 실험(블록 A 36회 + 블록 B 18회)으로 설계되어 있습니다.

      

      

        PHASE 2 — 강화학습 기반 적응형 튜닝 비교 (시뮬레이션)
        
Phase 1과 동일한 목적함수를 사용하기 위해 reward = -ITAE 형태의 보상 함수를 설계했습니다. 실기 적용이 아닌 시뮬레이션 환경으로 한정합니다.
